# MarketMap — แผนที่ตลาดนัดชุมชน

เว็บแอปพลิเคชันสำหรับค้นหาตลาดนัดและร้านค้าในชุมชนผ่านแผนที่ ผู้ใช้ปักหมุดตลาด เจ้าของตลาดจัดการตลาดและร้านค้าของตน และผู้ดูแลระบบตรวจสอบข้อมูลก่อนเผยแพร่ พัฒนาด้วย PHP, MySQL, Bootstrap และ Leaflet.js

> หมายเหตุ: โปรเจกต์นี้จัดทำขึ้นเพื่อการศึกษาและเก็บเป็นแฟ้มสะสมผลงาน (Portfolio) ข้อมูลในฐานข้อมูลตัวอย่างเป็นข้อมูลสมมติ

## ฟีเจอร์หลัก

### ผู้ใช้ทั่วไป
- ดูตลาดนัดบนแผนที่แบบโต้ตอบ (Leaflet.js) และค้นหาจากชื่อตลาด ชื่อร้านค้า หรือหมวดหมู่ร้านค้า
- ดูรายละเอียดตลาด เวลาเปิด-ปิด และรายการร้านค้า
- กดนำทางไปยังตลาดด้วย Google Maps
- แจ้งข้อมูลผิดพลาด เช่น หมุดผิดตำแหน่ง
- สมัครสมาชิก เข้าสู่ระบบ และเปลี่ยนรหัสผ่าน

### เจ้าของตลาด (Market Owner)
- ลงทะเบียนเป็นเจ้าของตลาดพร้อมแนบเอกสารยืนยันตัวตน
- เพิ่ม แก้ไข และลบตลาดของตนเอง (ปักหมุดตำแหน่งบนแผนที่)
- จัดการคำร้องขอเปิดร้านค้าในตลาดของตน

### เจ้าของร้านค้า (Shop)
- ส่งคำร้องขอเปิดร้านในตลาดที่ต้องการ
- เพิ่มและแก้ไขข้อมูลร้านค้า พร้อมหมวดหมู่และรูปภาพ

### ผู้ดูแลระบบ (Admin)
- แดชบอร์ดภาพรวมระบบ
- จัดการบัญชีผู้ใช้
- อนุมัติหรือปฏิเสธตลาดและคำร้องยืนยันตัวตนเจ้าของตลาด
- จัดการรายงานปัญหาที่ผู้ใช้แจ้งเข้ามา

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| Frontend | HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons |
| แผนที่ | Leaflet.js (แผนที่พื้นฐานจาก OpenStreetMap / CARTO) |
| Backend | PHP (MySQLi) |
| ฐานข้อมูล | MySQL / MariaDB |

## วิธีติดตั้งและรัน (Localhost)

1. **ติดตั้ง XAMPP** (หรือโปรแกรมจำลองเซิร์ฟเวอร์อื่นที่รองรับ PHP และ MySQL)
2. **คัดลอกโปรเจกต์** ไปไว้ที่ `C:\xampp\htdocs\market_map`
3. **สร้างฐานข้อมูล** เปิด phpMyAdmin (`http://localhost/phpmyadmin`) ไปที่แท็บ Import แล้วเลือกไฟล์ `schema.sql` ระบบจะสร้างฐานข้อมูล `market_map` พร้อมตารางให้
4. **ตั้งค่าการเชื่อมต่อ** คัดลอก `db.example.php` เป็น `db.php` แล้วแก้ค่าให้ตรงกับเครื่อง
   ```php
   $host = "localhost";
   $user = "root";
   $pass = "";
   $db   = "market_map";
   ```
5. **สร้างโฟลเดอร์เก็บไฟล์อัปโหลด** ถ้ายังไม่มี ให้สร้าง `uploads/documents`
6. **เปิดใช้งาน** ที่ `http://localhost/market_map`
7. **สร้างผู้ดูแลระบบคนแรก** สมัครสมาชิกผ่านหน้า Register จากนั้นใน phpMyAdmin เปิดตาราง `users` แล้วแก้คอลัมน์ `role` ของบัญชีนั้นเป็น `admin`

## บทบาทในระบบ (`users.role`)

| role | ความหมาย |
|---|---|
| `user` | ผู้ใช้ทั่วไป |
| `market_owner` | เจ้าของตลาด |
| `shop` | เจ้าของร้านค้า |
| `admin` | ผู้ดูแลระบบ |

## โครงสร้างโปรเจกต์

```
market_map/
├── index.php                  # หน้าแรก แผนที่ตลาดและช่องค้นหา
├── login.php / register.php   # เข้าสู่ระบบ / สมัครสมาชิก
├── forgot_password.php        # เปลี่ยนรหัสผ่าน
├── market_detail.php          # รายละเอียดตลาดและร้านค้า
├── add_market.php             # เพิ่มตลาด (ปักหมุด)
├── edit_market.php            # แก้ไขตลาด
├── add_shop.php / edit_shop.php  # จัดการร้านค้า
├── request_owner.php          # ลงทะเบียนเป็นเจ้าของตลาด
├── request_shop.php           # ขอเปิดร้านค้า
├── report_market.php          # แจ้งข้อมูลผิดพลาด
├── admin_dashboard.php        # แดชบอร์ดผู้ดูแลระบบ
├── admin_verify.php           # ตรวจสอบและอนุมัติ
├── manage_users.php           # จัดการผู้ใช้
├── manage_markets.php         # จัดการตลาด
├── manage_shop_requests.php   # จัดการคำร้องขอเปิดร้าน
├── get_markets.php / search_api.php  # API ส่งข้อมูลให้แผนที่และค้นหา
├── db.example.php             # ตัวอย่างไฟล์เชื่อมต่อฐานข้อมูล
├── schema.sql                 # โครงสร้างฐานข้อมูล (ไม่มีข้อมูลจริง)
├── css/  js/                  # Bootstrap, Leaflet และไฟล์สไตล์
└── uploads/                   # ไฟล์ที่ผู้ใช้อัปโหลด (ไม่ถูกเก็บใน Git)
```
